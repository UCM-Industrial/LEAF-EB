# Changelog

## 2026.08.27 — Initial public release

- First public release of LEAF-EB.
- Added six progressive, commented examples covering deterministic analysis,
  Monte Carlo simulation, BESS, methane production and reconversion,
  constant-output nuclear operation and load-following nuclear operation.
- Added synthetic daily and hourly datasets for self-contained examples.
- Added public documentation and user manual.
- Added automated tests and GitHub Actions continuous integration.
- Added explicit Monte Carlo control through
  `simulation.monte_carlo.preserve_annual_targets`.
